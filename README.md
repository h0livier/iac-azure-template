# iac-azure-template

[![Terraform Continuous Integration](https://github.com/h0livier/iac-azure-template/actions/workflows/continuous-integration.yml/badge.svg)](https://github.com/h0livier/iac-azure-template/actions/workflows/continuous-integration.yml)

Terraform template to create an Azure Resource Group with a centralized naming convention.

## Objective

This project provides a simple foundation for starting Azure infrastructure with Terraform:

- configured AzureRM provider
- configured Azure Storage remote state backend
- Resource Group name generation through an external naming module
- creation of an Azure Resource Group

## Project structure

- `providers.tf`: Terraform version, required providers, and `azurerm` backend
- `environments/backend-dev.hcl`: backend settings for `dev`
- `environments/backend-test.hcl`: backend settings for `test`
- `environments/backend-prod.hcl`: backend settings for `prod`
- `main.tf`: naming module and `azurerm_resource_group` resource

## Prerequisites

- Terraform >= 1.14.1
- An Azure subscription
- Azure CLI installed
- Sufficient permissions on:
	- the backend Resource Group
	- the backend storage account
	- the target subscription to create the Resource Group
- Add the GitHub repository to the list of authorized repositories in the Azure Application used for deployment

## Azure authentication

Sign in before running Terraform:

```bash
az login
az account set --subscription "<SUBSCRIPTION_ID_OR_NAME>"
```

## Terraform backend

The backend type is declared in `providers.tf`, and each environment has its own backend config file:

- `environments/backend-dev.hcl`
- `environments/backend-test.hcl`
- `environments/backend-prod.hcl`

Each file sets:

- resource_group_name: `ohaymngmtproject`
- storage_account_name: `ohaymngmtstorage`
- container_name: `iac-azure-template`
- key: environment-specific (`dev.tfstate`, `test.tfstate`, `prod.tfstate`)

Adjust these values to match your environment before the first `terraform init` if needed.

## What this template deploys

In `main.tf`:

1. The external `iac-naming-helper` module builds the Resource Group name.
2. An Azure Resource Group is created:
	- name: generated by the naming module
	- location: `West Europe`

Values currently passed to the naming module:

- project: `test`
- type: `rg`
- environment: `d`

## Usage

From the project root:

```bash
terraform fmt
terraform init -reconfigure -backend-config=environments/backend-dev.hcl
terraform validate
terraform plan -var="environment=dev" -out tfplan
terraform apply tfplan
```

To use another environment, switch both flags:

```bash
terraform init -reconfigure -backend-config=environments/backend-test.hcl
terraform plan -var="environment=test" -out tfplan
```

## Quick customization

In `main.tf`, you can change:

- `location` to change the Azure region
- `data.project` for the project identifier
- `environment` for the environment (for example: d, t, p)

In `providers.tf`, you can change:

- the minimum Terraform version
- the `azurerm` provider version
- the backend settings

## Destruction

To delete the resources:

```bash
terraform destroy
```
